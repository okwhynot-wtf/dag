# Meta-problem exhibit notes

Companion to `formal/dictionary/MetaProblem.lean`.

## Claimed

Chalmers's **meta-problem** explanandum — systems report ineffability,
incompleteness, and an unstable self — is theorem-shaped behaviour of any
live self-representing ladder system:

| Report | Theorem |
|---|---|
| Opaque to itself | `Interior.self_opacity` |
| Self-model stale | `Interior.outdated_portrait` |
| Self won't sit still | `Interior.self_modeling_forces_restless` |
| Forced thin observer | `Observer.observers_forced` |

## Refused

The **hard problem** (qualia / "what it is like"). Spine scope already
commits: Interior entails nothing about experience. Neutral-monist reading
only.
